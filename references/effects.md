# エフェクト

エフェクトはすべて `templates/base.css` のクラスです。使うのは焦点の要素だけにします（SKILL.md の「派手さの予算」を参照）。強さレベル1では、ほとんどが動かないアクセントに変わります。

| クラス | 見た目 | 使う場所 | 補足 |
|---|---|---|---|
| `.ttl` | 虹色のグラデーションがゆっくり流れるタイトル（5秒周期） | 図のタイトル | lv1: ただの太字 |
| `.gold` | 暗い縁取り付きの金色グラデーション文字。光が呼吸するように強弱する（1.8秒） | 焦点の言葉1〜2個。答えのラベルやスタンプ | 読めるのは16px以上。縁取りがあるので明るい背景でもコントラストが保てる |
| `.rb` + 内側の `.in` | 箱の周りを虹色の光が回る（1周1.8秒。lv3は1.2秒） | 読者が最後に見るべき1つの箱 | 帯の幅は6px。2つ並べない |
| `.neon` / `.chip-on` | 影が明るくなったり薄れたりする（1.6秒） | 選択中のチップ、いま有効なゲート | lv1: 動かない枠線 |
| `.tb.t1`〜`.t4` | 重要度の段階バッジ。色・線種（点線・二重線・実線と光・虹色の縁）・★の数・言葉を一緒に変える。動かない | 深刻度、リスク、段の重要度（spec の `importance`） | lv1: t3・t4 の光と虹をなくす |
| `.btn` の押し込み | 押した瞬間に3px沈み、下の影がなくなる（`:active`） | すべてのボタン | 変わらない |
| `.cnt` | 数字が `--from` から `--to` へ数え上がる（`@property` の整数とカウンタ。1.4秒、終わり際をゆっくり）。動きを止めた状態では最後の値だけが出る。`@property` がない環境では途中で一度だけ最後の値に切り替わる。読み上げ用の本当の数字を `.sr` に持つ | compare の `metric` | 変わらない |
| `.gg` | 目標の線が入ったゲージ。アフターに切り替えると before の長さから伸び縮みし、目標に届けば「到達 ✓」がスタンプで出る。届いたかどうかは言葉と枠でも示す | compare の `metric.goal` | 到達の印は pop |
| 収束する輪（architecture の `focal`） | 焦点の箱に、1.8倍の輪が1回だけ縮んで重なり、消える（音ゲーのタップの輪）。ループしない。止まった状態では輪は見えない | architecture の焦点の箱 | 出さない |
| `.ci` | 斜めの帯が左から1回だけ割り込み、一言を見せてそのまま残る（0.55秒、減速して止まる）。文字は斜めにしない | explorer の `cases[].cutin`、compare の `before.cutin` / `after.cutin`（`reveal:"flip"` とは併用不可） | 斜めにせずアクセント色の帯。印刷は枠と文字だけ |
| 暗転（spec の `hush`） | 答えが出た瞬間に、見出しやほかの手順の動きを止め、文字のない飾り（線を流れる光、ボタンを横切る光）だけを1秒かけて薄くする。戻るときも1秒。文字は薄くしない | flow の焦点の手順、compare のアフター | 変わらない。動きを止める設定と印刷では薄くしない |
| ステップアップ（ladder の `stepup`） | 選んだ段の下の段が、下から順に「✓」の印とともに点く。色だけでなく印でも示す。一方向の変化で、点いたり消えたりしない | ladder | 印は stamp ではなく pop で出る |
| `.nb` | 変わったところに付く小さく傾いた札（ガチャの10連のまとめ画面の NEW）。出るときに1回だけ pop し、光らせ続けない | flow の `steps[].new`、compare の `items[].new` | 変わらない。印刷は枠と文字だけ |
| 周回バッジ（loop の `laps`） | 「×2」「×3」のバッジが0.8秒おきに1つずつスタンプで出て、並んだまま残る（パチンコの擬似連）。後のものほど大きく、回数は文字で書く。ループしないので、円を回る光と一緒に動き続ける要素は増えない | loop | バッジは pop で出て、光の輪がない |
| コンボとリーチ（combo） | 押した条件の番号が ✓ に変わり、CSS カウンタの「3/5」とバーが育つ。残り1つで「あと1つ！」が金文字で出て、残った条件の箱がネオンで脈動し「残りはこれ」の札が付く。全部そろうと結論がスタンプで出る。リールの回転は使わない（速い回転は明滅になる） | 全部そろって初めて成立する条件 | 脈動なし（動かない枠線）、スタンプは pop、金文字は濃い琥珀色 |
| スタンプカード（stampcard） | 選んだマスにだけ「済」のスタンプが `stamp` で1回落ちる。それより前のマスは動かずに済の状態（実線の枠、「済」、✓）になる。スタンプが同時に何個も落ちない。ループしない | stampcard | スタンプは pop で出る |
| めくり（explorer の `reveal:"flip"`） | 伏せたカードが0.6秒で1回だけ裏返る（`rotateY`）。ループしない | 予想してから答え合わせをさせたい答え | 変わらない。動きを止めると瞬時に切り替わり、印刷では表面だけ |
| `.shine` | 3秒ごとに光の帯がボタンを横切る | 主ボタン、警告の帯 | |
| `stamp` キーフレーム | 2.2倍から少し回転しながら落ちてくる | 答えが出る瞬間、「完了！」（英語は "Done!"） | `animation: var(--enter) …` 経由で使う。lv1 では `pop` に差し替わる |
| `pop` キーフレーム | 6px 浮き上がりながらフェードイン | 補助的な内容の表示 | |
| `.btn` | 立体的な縁と光のあるオレンジのピル型ボタン | 状態を切り替える `<label>` | |

## 安全のための上限（緩めない）

- **明るさが変わるものはループ周期を1秒以上にします。** 急な点灯と消灯の繰り返しにはしません。回転するグラデーションの枠は、ある1ピクセルの色が1周に1回変わります。1周を1秒以上に保ちます。検査スクリプトは、0.5秒未満の無限ループを FAIL にします（Zenn は「激しく点滅する表示」を禁止しています。WCAG 2.3.1 は1秒に3回を超える点滅を禁じています）。
- **最後のフレームは基本スタイルと同じにします。** 登場アニメーションは、要素の通常の CSS の状態で終わるようにします。動きを減らす設定の人や PDF では、アニメーションがまったく動かないからです。
- **transform ははみ出します。** `stamp` は2.2倍まで拡大します。その間ページが一瞬広がり、高さ固定の埋め込みの中に横スクロールバーが出ます。`.dd` には `overflow:hidden` が付いています。外さないでください。
- **明るい背景の金文字には縁取りが必要です。** `-webkit-text-stroke` と暗いドロップシャドウがないと、金文字はクリーム色の背景に溶けて見えなくなります。

## トークン

`--a` アクセント（オレンジ）、`--b` 青、`--g` 緑、`--r` 赤、`--y` 黄、`--v` 紫。それぞれに薄い背景用の `--*s` があります。ほかに `--bg`、`--card`、`--ink`、`--mut`、`--line`、光の輪用の `--glow` があります。ダークモードの値は `build.py`（`DARK_VARS`）が差し込みます。見た目を変えるときは両方を変えてください。
