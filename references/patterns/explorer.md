# パターン: explorer

「X のときは Y する。Z ではない」を3〜8個の状況で見せます。読者は左側（狭い画面ではチップ）で状況を選びます。パネルには状況、取り消し線付きのよくある間違い（任意）、虹色の枠の中にスタンプされる答えが出ます。

覚え違いが多い判断表に使います。エラー処理、エスカレーションのルール、AI のフォールバック動作、オンコールの手順書などです。見せる価値のある「よくある間違い」がなければ `bad` を省いてください。それでも成り立ちます。

## Spec

```json
{
  "pattern": "explorer",
  "title": "API 呼び出しが失敗した。どうする？",
  "bad_label": "よくある間違い",
  "good_label": "こうする",
  "cases": [
    {"label": "429 Too Many", "situation": "レート制限にかかった",
     "bad": "すぐにループで再試行する", "good": "Retry-After の時間だけ待ってから再試行する"}
  ],
  "note": "出典: … ／「よくある間違い」は説明用の例です"
}
```

| フィールド | 必須 | 補足 |
|---|---|---|
| `cases[].label` | はい | チップの文字。ASCII 22文字、CJK 11文字までならチップが1行に収まる |
| `cases[].situation` | いいえ | パネルの見出し。既定は `label` |
| `cases[].bad` | いいえ | 取り消し線付きで表示。作った例なら `note` にそう書く |
| `cases[].good` | はい | 答え。1文で |
| `bad_label`, `good_label` | いいえ | 既定は spec がひらがなかカタカナを含むか `"lang": "ja"` なら「よくある間違い」「こうする」、そうでなければ "Common mistake"、"Do this instead"（SKILL.md の `lang` を参照） |
| `cases[].importance` | いいえ | 重要度 1〜4。状況の見出しの横に段階バッジ（★の数と言葉）が出る。4（最重要、虹色の縁）は1つの図に1つまで。既定の言葉は「低・中・高・最重要」（英語の spec では Low・Medium・High・Critical） |
| `cases[].importance_label` | いいえ | バッジの言葉を変える。1〜2語。`importance` と一緒に書く |
| `reveal` | いいえ | `"flip"` にすると、答えが伏せたカードになる。裏面に `cases[].hint`（既定は「答えを予想してからめくる」）と「めくる ▶」のボタンが出て、押すとカードが裏返って答えが出る。読者が予想してから答え合わせをするので、答えが記憶に残りやすい。ボタンの文言は `flip_label`、`unflip_label` で変えられる。既定（`"stamp"`）は答えがスタンプで出る |
| `cases[].hint` | いいえ | `reveal:"flip"` のときの裏面の言葉。予告を短く（例: 「重要度★★：どこを直す？」） |
| `flip_label`, `unflip_label` | いいえ | めくる・伏せるボタンの言葉。短く |

## 上限

- ケースは2〜8個（範囲外だと build.py が止まります）。3個以上がいちばん読みやすいです。8個を超えるとスマホで500px に収まりません。図を2つに分けてください。
- 印刷と PDF では先頭のケースを表示します。いちばん大事なものを先頭に置きます。
- 焦点は答えの箱です。ほかに金色や虹色の要素を足さないでください。
