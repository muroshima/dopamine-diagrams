# パターン: combo

「全部そろって初めて成立する条件」を、読者が1つずつ押して確かめる図です。音ゲーのコンボ（成功が続くと数が育ち、全部そろうと FULL COMBO）と、パチンコのリーチ（あと1つで「あと1つ」、全部で確定）を借りています。

条件の箱を押すと、番号が ✓ に変わり、枠が破線から実線になります。下のメーターは「3/5」と数え、そろった分だけバーが左から伸びます。残りが1つになると「あと1つ！」が金文字で出て、残った条件の箱が光り「残りはこれ」の札が付きます。全部そろうと、鍵のかかった欄が開き、結論が虹色の枠の中にスタンプで出ます。

リリース判定の条件、セキュリティ要件、作業前のチェックリストなど、「1つでも欠けたら成立しない」と伝えたいときに使います。条件の重さに差があるなら explorer か ladder、順番に意味があるなら flow を使ってください。

## Spec

```json
{
  "pattern": "combo",
  "title": "今日リリースしてよいか？ 5つの条件",
  "conditions": [
    {"tag": "CI", "text": "main のテストがすべて通っている"},
    {"tag": "レビュー", "text": "2人以上が承認している"}
  ],
  "result": {"stamp": "リリースOK", "text": "タグを打ってデプロイする。1つでも欠けたら明日に回す"},
  "prompt": "確かめた条件を押す",
  "reach_label": "あと1つ！",
  "full_label": "そろった！",
  "note": "例として作った内容です"
}
```

| フィールド | 必須 | 補足 |
|---|---|---|
| `title` | はい | 何がそろうと何が成立するのか |
| `conditions[].text` | はい | 確かめられる条件を1つ。スマホでは1列に積むので、6個なら2行に収まる長さにする |
| `conditions[].tag` | いいえ | 分類ラベル。ASCII 14文字、CJK 7文字まで |
| `result.text` | はい | 全部そろったときの結論 |
| `result.stamp` | いいえ | 結論に押す金色のスタンプ。既定は「確定！」（英語は "Unlocked!"） |
| `prompt` | いいえ | まだ「あと1つ」でないときにメーターの横に出る文。既定は「確かめた条件を押す」 |
| `count_label` | いいえ | 「3/5」の後ろに付く言葉。既定は「クリア」 |
| `reach_label` | いいえ | 残り1つのときの金文字。既定は「あと1つ！」 |
| `full_label` | いいえ | 全部そろったときの金文字。既定は「そろった！」 |
| `last_label` | いいえ | 残った条件の箱に付く札。既定は「残りはこれ」 |
| `locked_label` | いいえ | そろうまで結論の欄に出る文。既定は「全部そろうと結論が出る」 |

既定の文言は spec の言語に合わせて日本語か英語になります（SKILL.md を参照）。

## しくみ

- 条件ごとに隠した checkbox を置き、`counter-increment` で数えます。数を出す要素は input より文書の後ろにあるので、合計が見えます。
- 「あと1つ」は、その条件だけ `:not(:checked)` でほかは `:checked` という兄弟セレクタの連鎖を、条件の数だけ作って判定します。`:has()` は使いません。
- バーの区切りは条件と1対1で、押された区切りに `order:0` を付けて左に寄せます。どの順で押しても左から伸びて見えます。
- 状態は数字（「3/5」）、言葉（「あと1つ！」「そろった！」「残りはこれ」）、印（番号と ✓）、枠の線種（破線と実線）で示し、色だけには頼りません。
- 回転するリールは使いません。速い回転は実質の明滅になるからです。

## 派手さ

- lv1: スタンプは pop になり、金文字は濃い琥珀色の文字（背景とのコントラスト4.5:1以上）、残った条件の箱は動かない枠線、結論の枠はアクセント色1色です。
- lv2: 残った条件の箱がネオンで脈動し（1.6秒）、「あと1つ！」と結論のスタンプが金色に光ります。
- lv3: 脈動と枠の回転が速くなります（1.2秒）。

## 上限

- 条件は2〜6個（範囲外だと build.py が止まります）。広い画面では4個以上を2列に、3個以下を1列に並べます。スマホでは1列です。
- 条件や結論が長く、スマホで Zenn の高さ500px を超えそうなときは build.py が警告します。
- 印刷と PDF では、全部の条件に ✓ を付け、「N/N」と「そろった！」と結論を表示します。押せない紙の上では、そろった状態がいちばん役に立つからです。
