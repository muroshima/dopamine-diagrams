# パターン: loop

ステップが円の上に並び、光の破線が円を回ります。各ステップは順番に光ります。任意で、円の上に目的の箱を置けます。目的の箱から最初のステップへ矢印が入り、最後のステップから目的へ赤い破線で戻ります（「目的そのものが変わったら最初に戻る」）。

循環に使います。作る・測る・学ぶ、障害の振り返り、リリース後の要件の更新などです。

## Spec

```json
{
  "pattern": "loop",
  "title": "要件はリリース後も動き続ける",
  "goal": "目的",
  "steps": ["引き出す", "仕様にする", "作る", "運用する", "声を集める"],
  "center": {"text": "もう一周", "sub": "変わるのが当たり前"},
  "back_label": "目的が変わった？ 最初に戻る",
  "laps": 3,
  "hush": true
}
```

| フィールド | 補足 |
|---|---|
| `steps` | 短いラベルを3〜6個（ASCII 12文字、CJK 7文字まで。超えると build.py が警告し、3〜6個の範囲外だと止まる） |
| `goal` | 任意。ないと円が上に詰まり、図が低くなる |
| `back_label` | 任意。`goal` が必要。赤い戻り線と凡例を描く |
| `center` | 任意。円の中央に金色の言葉と灰色の1行を置く |
| `laps` | 任意。周回バッジ（パチンコの擬似連）。整数 N（2〜5）で「×2」〜「×N」、文字列のリスト（1〜4個、空文字は不可）でその言葉のバッジになる。見出しの右に、0.6秒後から0.8秒おきに1つずつスタンプで出て（lv1 は pop）、そのまま残る。ループしない。後のバッジほど文字が2pxずつ大きく、最後の1つだけ動かない光の輪が付く。円の図（SVG）の外に置くので、目的・手順・中央の言葉には重ならない。狭い画面では見出しの下に折り返す |
| `hush` | 任意。`true` にすると、手順が円を1周光り終えたとき（`laps` があれば、最後のバッジが出た周の終わり）に答えが出る。ページを開いてから約 n 秒後で、時刻は手順の数 n で決まる。その瞬間に、中央の言葉がスタンプで出て（lv1 は pop。それまでは見えない）、円を回る光・赤い戻り線・目的の箱の光・見出しの虹色がその場で止まり、続けて円を回る光が1.2秒かけて薄くなり、円の中央の周りの背景が1.2秒かけて少し暗くなる（見出しの帯は暗くしない）。手順の点灯（lv2・lv3。lv1 はもともと光らない）はちょうど1周を終えて止まる。クリックはないので、暗くなったまま戻らない。ページの下の方の図では、読者が着く前に終わって最後の状態だけが見える。赤い凡例の文字は暗くした背景でも読めるよう濃い赤（`--rt`）にする |

## 上限

- SVG は幅400ユニットで、表示は最大360px です。目的と凡例があっても Zenn の高さ500px に収まります。文字は16ユニットで、340px でも12px 以上を保ちます。
- グラデーション塗りの文字は、Chrome の PDF では箱になって印刷されます。印刷時は単色のオレンジに切り替えます。
- 周回バッジは「周回」のラベルとともに見出しと同じ行に入ります。見出しとバッジが PC 幅で1行に収まらないと、バッジが折り返して Zenn の高さ500px を超えることがあり、そのときは build.py が警告します。スマホ幅では1行増えます。読み上げは「周回: 2周目, 3周目」です。印刷では背景を付けず、濃いオレンジの文字と枠にします。
