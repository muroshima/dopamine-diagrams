# パターン: decompose

ふわっとした一文（「法令を守る」「安全にする」「UX を改善する」）が破線の箱に入り、下に警告が出ています。1回クリックすると、箱の線が実線になって光り、2〜6個の具体的な項目が順にスタンプされ、角に金色のスタンプ（「テストできる！」）が押されます。

「この一文は分解するまで作れないし、テストもできない」と伝えたいときに使います。

## Spec

```json
{
  "pattern": "decompose",
  "title": "スローガンを要件に変える",
  "root": {"kicker": "あいまいな要件", "text": "システムを安全にする"},
  "button": "分解する ▶",
  "back": "戻る",
  "hint": "この一文のままでは作れないし、テストもできない",
  "done": "テストできる！",
  "stepup": ["侵入されにくく、されても追える", "5つの項目で合否を判定できる"],
  "children": [
    {"tag": "アクセス", "text": "管理者は MFA でサインインする"}
  ],
  "note": "例として作った内容です"
}
```

| フィールド | 必須 | 補足 |
|---|---|---|
| `root.text` | はい | ふわっとした一文 |
| `root.kicker` | いいえ | 上に付く小さなラベル（「外部からの要求」「スローガン」） |
| `children[].text` | はい | 具体的で確かめられる項目を1つ |
| `children[].tag` | いいえ | 分類ラベル。ASCII 14文字、CJK 7文字まで。折り返さないこと |
| `button`, `back`, `hint`, `done` | いいえ | ボタンの文言、ボタンの下の警告、金色のスタンプの文字 |
| `title` | いいえ | 前後の本文で紹介済みなら省く |
| `stepup` | いいえ | 1〜3個の文字列。`root.text` を少しずつ具体にした文を、最後がテストできる文になるよう順に並べる。クリックすると、項目より先にこの文が0.6秒おきに1つずつ「▼」付きで出て、後の文ほど少し大きくなり、最後の文だけがスタンプで落ちて虹色の枠に入る（ステップアップ）。金色の完了スタンプは、最後の文と同時に pop で出る。そのあと項目が、薄い下書きの状態から濃くなって出る。項目が出始めるのは押してから2秒以内。省くと今までどおりすぐ項目が出る |

## 上限

- 子は2〜6個（範囲外だと build.py が止まります）。広い画面では5個までが1行に並び、6個は3×2になります。スマホでは縦に積みます。
- 印刷と PDF では、ボタンなしで、分解後の状態をスタンプ付きで表示します。
- `stepup` の文は1行に収めます。後の段ほど大きいので、340px のスマホで1行に入るのは、最後の段（虹色の枠）が和文15〜16文字・英文30文字ほど、それより前の段が和文17文字・英文32文字ほどです。長いと build.py が段ごとに警告します。
- build.py は分解後のスマホでの高さを見積もり（文の折り返しと項目の行数を含む）、500px に近いと警告します。段か項目を減らすか、短くしてください。
- 印刷と PDF では、段も最後の大きさで、root の下に間を空けて並びます。
