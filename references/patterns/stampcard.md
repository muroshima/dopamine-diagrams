# パターン: stampcard

ソシャゲのログインボーナスのように、全部のマスを最初から並べ、最後のマス（ごほうび）を虹色の枠と金文字で大きく見せます。マスをクリックすると、そのマスに「済」のスタンプが押され、そこまでのマスも済の状態になります。下のパネルには、選んだマスで何をするかが出ます。最初は何も選ばれていないので、パネルは読者にどこまで進んだかを選ぶよう促します。

導入計画や学習のロードマップに使います。途中の手順は地味でも、最後に何が手に入るかを先に見せたいときです。

## Spec

```json
{
  "pattern": "stampcard",
  "title": "テスト自動化、7週間で何が手に入る？",
  "days": [
    {"label": "1週目", "name": "落ちる場所を数える", "detail": "直近3か月の障害と手戻りを並べ、どこで壊れたかを数える"},
    {"label": "2週目", "name": "1本だけ書く", "detail": "いちばん壊れやすい処理に、テストを1本だけ書く"},
    {"label": "3週目", "name": "金曜もリリース", "detail": "壊れたら CI が先に教えてくれる。曜日を気にせず出せる"}
  ]
}
```

| フィールド | 補足 |
|---|---|
| `days[].name` | 必須。マスの中に出る短い名前。最後のマスの `name` が、金文字で大きく出るごほうび |
| `days[].label` | マスの見出し。既定は「N日目」（英語は "Day N"）。週や段階なら「1週目」「Step 1」のように書く |
| `days[].detail` | 選んだときに下のパネルに出る説明。1〜2文 |
| `current` | 最初から選んでおくマスの、0始まりの番号。進み具合を見せたいときに使う。既定はなし（何も選ばず、促しの文を出す） |
| `prompt` | 何も選んでいないときにパネルに出る文。既定は「どこまで進んだ？ マスをクリック」 |
| `done_label` | スタンプの文字。既定は「済」（英語は "Done"） |
| `reward_label` | 最後のマスに付くバッジの文字。既定は「ごほうび」（英語は "Reward"） |

## 動き

- 選んだマスにだけ、スタンプが `stamp` で落ちてきます（強さ1では `pop`）。それより前のマスは、動かずに済の状態（緑の実線の枠、「済」のスタンプ、見出しの ✓）に変わります。複数のスタンプが同時に落ちる騒がしさを避けるためです。
- 済のマスは、色だけでなく「済」の文字と ✓ でも示します。まだのマスは点線の枠と、空のスタンプ欄です。
- 最後のマスは虹色の枠（`.rb`）と、19px の金文字です。19px の太字は大きい文字の扱いになるので、強さ1の単色でも読めます。
- 選んだマスは少し浮き、枠が光ります（強さ1では光らない枠線だけ）。最後のマスは虹色の枠があるので浮かせません。

## 上限

- マスは3〜8個（範囲外だと build.py が止まります）。広い画面では6個までを1行に、7〜8個は2行に並べ、ごほうびを右に2行分の高さで置きます。
- スマホ（560px 以下）では3列に折り返し（3マスのときは2列）、ごほうびはその行の残りを埋めます。残りが1マス分しかないときは、ごほうびを次の行の全幅に置きます。
- `name` はマスの中で3行まで。超えそうなとき、マスより長い英単語があるとき、`label`・`done_label`・`reward_label` がマスに収まらなさそうなときは、build.py が警告します（目安: ASCII 20文字、CJK 12文字まで）。
- 印刷と PDF では、マスとスタンプはそのときの状態のまま、パネルには最後のマス（ごほうび）の説明を出します。図の言いたいことは「最後に何が手に入るか」だからです。
